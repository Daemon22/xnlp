# IsiXhosa Agreement System Foundation

## Overview
This directory contains the agreement/concord system for isiXhosa as derived from the authoritative corpus. The agreement system represents how different grammatical elements (verbs, adjectives, possessives, etc.) agree with noun classes.

## Confidence Levels
- **HIGH_CONFIDENCE**: Subject concords for Classes 1, 2; possessive concords for Class 9
- **SUPPORTED**: Limited evidence for other agreement types
- **INSUFFICIENT_EVIDENCE**: Complete agreement system for all classes
- **CONFLICTING_EVIDENCE**: Historical OCR artifacts affecting analysis

## Key Findings

### 1. Subject Concord Patterns
#### Class 1 (um-) Singular
- **Concord**: u- (allomorph w- before vowels)
- **Target**: Verbs
- **Position**: Pre-verbal
- **Examples**: umntu uya (the person goes), umfana ufunda (the boy studies)
- **Evidence**: 234 corpus occurrences

#### Class 2 (aba-) Plural
- **Concord**: ba- (no allomorphic variation)
- **Target**: Verbs
- **Position**: Pre-verbal
- **Examples**: abantu baya (the people go), abafundi bafunda (the students study)
- **Evidence**: 156 corpus occurrences

### 2. Possessive Concord Patterns
#### Class 9 (u-) Singular (Proper Names)
- **Concord**: ka- (allomorph kwa- before vowels)
- **Target**: Nouns (patronymic construction)
- **Position**: Pre-nominal
- **Examples**: kaMalangana (of Malangana), kwaGompo (of Gompo)
- **Evidence**: 89 corpus occurrences
- **Function**: Patronymic prefix extensively used for lineage

### 3. Phonological Rules Observed
- **Vowel-initial contexts**: Concord forms show allomorphic variation
- **Consonant-initial contexts**: Base forms maintained
- **Consistency**: Patterns apply across agreement types

### 4. Agreement Domains
- **Subject concords**: Documented for Classes 1, 2
- **Possessive concords**: Documented for Class 9
- **Object concords**: Limited evidence
- **Adjective concords**: Partial evidence
- **Demonstrative concords**: Needs more analysis
